# ＳＴＹＬＡＤＡＹ 🎀 穿搭快拍 — 我的穿搭日記跟電子衣櫥

一頁式、免安裝、零外部依賴的個人穿搭管理工具：把衣服「掛」進有實體感的三層電子衣櫥，記錄每天穿了什麼，再用數據告訴你哪些衣服你其實根本不會穿。

> 本專案為單一 `index.html` 檔案，不需要後端、不需要建置工具，所有資料只存在你自己的裝置裡。

## 功能

- **👗 電子衣櫥**：三層掛衣桿模式（外套/洋裝、上衣、下身、底層收納格）與卡片詳情模式可切換；依顏色、分類、穿著狀態篩選，依穿過天數 / CPW / 價格排序，支援關鍵字搜尋。
- **🗓️ 穿搭月曆與日記**：月曆格子自動生成當日穿搭微縮圖；記錄日期、天氣、場合與日記備註；「拯救冷宮單品挑戰」會自動挑出最少穿的單品邀你穿它出門。
- **✨ 自由畫板 & 附魔去背**：上傳衣服實拍照自動去除白底/淺色背景，變成乾淨的去背單品圖；單品可在畫板上自由拖曳、縮放、調整層級，比較搭配效果，也能隨機產生靈感穿搭。
- **📊 數據與不會穿診斷**：衣櫥使用率、最常穿色系圓餅圖、Top 5 常穿排行榜、各類型「擁有佔比 vs 實際穿搭佔比」落差圖、單次穿著成本（CPW）診斷表、冷宮單品清單（可調整判定標準：穿 ≤ 0 / 1 / 2 天）。
- **🔥 2026 流行穿搭建議**：4 組 2026 秋冬穿搭公式（巴恩風工裝、V領學院疊穿、薄厚異材質、酒紅美拉德），自動比對你的衣櫥已有單品，並附「防閒置滅火提醒」，可一鍵加入衣櫥或送去畫板試擺。
- **⚡ 快速打卡**：在衣櫥直接點「今天穿+1」即可記錄當日穿著（同一天同一件不重複計算）。

## 如何在本機開啟

最簡單的方式：直接用瀏覽器開啟 `index.html`（雙擊檔案即可）。

若遇到瀏覽器對 `file://` 的本機儲存限制，建議起一個本機靜態伺服器：

```bash
# 任選一種，在專案目錄執行
python3 -m http.server 8000
# 或
npx serve .
```

然後開啟 `http://localhost:8000`。

## GitHub Pages 部署說明

1. 在 GitHub 建立一個新 repository（例如 `styladay`），把本專案的 `index.html`（以及本 README）推上去，`index.html` 需放在 repository 根目錄。
2. 到 repository 的 **Settings → Pages**。
3. **Build and deployment** 的 Source 選擇 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等待約 1 分鐘，Pages 會顯示公開網址，格式為 `https://<你的 GitHub 帳號>.github.io/styladay/`。
5. 之後每次 push 更新 `index.html`，Pages 都會自動重新部署。

注意：GitHub Pages 是公開的靜態網站，任何人都能開啟頁面；但每位訪客的衣櫥資料都只存在**他自己瀏覽器**的本機儲存裡，不會上傳到 GitHub，也不會互相看見。

## 資料儲存說明

- **儲存位置**：全部在本機瀏覽器，不經過任何伺服器、沒有帳號系統。
- **三重備援**：
  1. `localStorage`（鍵名 `styladay_wardrobe_iq_clean_v3`，並相容讀取舊版鍵名）；
  2. `IndexedDB`（資料庫 `StylaDayPermanentDB`）；
  3. `window.name` 視窗記憶（同一分頁重新整理時可還原）。
- **容量提醒**：去背照片會以圖片 data URL 形式存入上述空間，件數多時可能額滿；額滿時畫面會跳出提醒，請至「📦 備份/還原記憶」匯出。
- **備份/還原**：可一鍵複製「記憶代碼」貼到備忘錄保存，或下載 `.json` 備份檔；換裝置/換瀏覽器後，貼上代碼或上傳備份檔即可還原。
- **清除資料**：頁面右上角「清空資料」會刪除全部衣物與穿搭紀錄；清除瀏覽器的網站資料也會達到相同效果，請先備份。

## 已知限制

- 自動去背採用簡易演算法（以淺色/近白背景為主），複雜背景、陰影重的照片去背效果有限，建議在白牆或淺色背景前拍攝衣物。
- 換瀏覽器或使用無痕模式時，本機資料不會跟著走，請使用備份功能搬移。
